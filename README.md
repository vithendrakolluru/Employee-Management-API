# Employee Management API

A RESTful API built with ASP.NET Core Web API for managing employee records.

## Tech Stack
- C# / ASP.NET Core 8.0
- Entity Framework Core
- SQL Server
- Swagger / OpenAPI

## Features
- Get all employees
- Get employee by ID
- Add new employee
- Update employee
- Delete employee

## How to Run
1. Clone this repo
2. Open in Visual Studio
3. Press F5 to run
4. Open Swagger UI to test APIs
